# יומן עבודה · سجل العمل · Work Diary

אפליקציה לניהול יומן עבודה באתר בנייה: ממלאים את הנתונים של היום ומקבלים **דוח PDF
מעוצב** (או Word) בתבנית של הטופס המודפס.

- **שלוש שפות** — עברית, ערבית ואנגלית. החלפת שפה בהגדרות משנה את כל האפליקציה
  **וגם את הדוחות** שמופקים: כותרות, תוויות, שמות הקבצים וכיוון הכתיבה.
- **מצב בוקר ומצב לילה** (או אוטומטי לפי המכשיר).
- **PDF אמיתי** שנוצר בתוך האפליקציה — בלי כותרות של הדפדפן, בלי כתובת URL מודפסת,
  ותמיד עמוד אחד מסודר.
- **עובדת בלי אינטרנט** — כל הנתונים נשמרים במכשיר עצמו.
- **אפליקציית Mac** מלאה, בנוסף לאתר ולאפליקציה בנייד.
- **חתימות דיגיטליות**, **תמונות מהאתר**, **לוגו החברה** בראש הדוח, והשלמה אוטומטית
  שנלמדת מהיומנים הקודמים.
- **דוח מרוכז** לתקופה עם סיכומי עובדים לפי מקצוע, שעות ציוד וכמויות בטון.

## הפעלה מהירה

```bash
npm install
npm run dev        # פיתוח
npm run build      # בנייה לפרודקשן (התיקייה dist)
```

## עדכון — לחיצה כפולה

בתיקיית הפרויקט יש קובץ **`עדכון.command`**. לחיצה כפולה עליו:

1. מתקינה מחדש את התלויות
2. בונה מחדש את האתר
3. בונה מחדש את אפליקציית ה-Mac

בסוף מוצג סיכום והחלון נשאר פתוח. אם משהו נכשל, ההודעה נשארת על המסך.

> בפעם הראשונה macOS עשוי לבקש אישור להרצת הקובץ: לחיצה ימנית ← Open.

## אפליקציית ה-Mac

```bash
npm run app:build
```

התוצאה:

- `release/mac-arm64/יומן עבודה.app` — האפליקציה
- `release/יומן עבודה-1.0.0-arm64.dmg` — קובץ התקנה לגרירה ל-Applications

האפליקציה **אינה חתומה** (אין חשבון מפתח של Apple), ולכן בפתיחה הראשונה צריך
**לחיצה ימנית על האפליקציה ← Open ← Open**. אחרי פעם אחת היא נפתחת רגיל.

באפליקציה, שמירת דוח פותחת חלון שמירה אמיתי של macOS במקום להוריד לתיקיית ההורדות.

## התקנה לנייד

פותחים את הכתובת בדפדפן בטלפון ← תפריט ← **הוסף למסך הבית**. מאותו רגע היא נפתחת
כמו אפליקציה רגילה ופועלת גם ללא קליטה.

## מבנה היומן

כל יום הוא דף אחד, זהה במבנה לטופס המקורי:

| חלק | שדות |
| --- | --- |
| פרויקט | שם הפרויקט, כתובת, שם חברה |
| תאריך–מזג האוויר | תאריך, מזג אוויר |
| רישום יומי של עובדים וציוד | צוות הנהלה (שם, תפקיד) · קבלן (מקצוע, כמות עובדים) · ציוד (סוג, כמות, שט"ע) |
| תיאור העבודה שבוצעה | טקסט חופשי + פרטי יציקה (תיאור, גודל-כמות, משאבה, סוג וכמות בטון, הערות) |
| חתימות | הערות המפקח, חתימת מפקח, חתימת מנ"ע |

## גיבוי

הנתונים נמצאים **רק במכשיר**. בהגדרות יש **הורד גיבוי** שמייצא הכול לקובץ אחד (כולל
תמונות, חתימות ולוגו), ו**שחזר מגיבוי** שמחזיר אותו — גם למכשיר חדש. מומלץ לגבות
מדי שבוע.

## גופנים

הדוחות מטמיעים גופנים פתוחים (SIL OFL): **Heebo** לעברית ולטינית ו-**Cairo** לערבית.
שני הגופנים מוטמעים בכל מסמך, כך שיומן שנכתב בעברית נשאר קריא גם בדוח בערבית.
לרענון: `npm run fonts`.
